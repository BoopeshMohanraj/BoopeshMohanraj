## Selected projects

**Quantitative finance**

- **[Dynamic VaR — Portfolio Risk & Stress Testing](/BoopeshMohanraj/Dynamic-Var-stress-testing-engine)** — Portfolio risk system with static and dynamic (GARCH / EWMA / GJR-GARCH filtered historical simulation) VaR, stress testing, Mean-CVaR optimization, and Kupiec backtesting. Live Streamlit dashboard.
